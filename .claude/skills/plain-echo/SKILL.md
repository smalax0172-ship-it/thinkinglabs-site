# plain-echo

An idea that only sounds good in dressed-up language is not ready. This skill undresses it.

When triggered, restate the user's idea under these rules:

1. Fewest, flattest words a tired stranger would use. Short sentences.
2. No jargon, no framework vocabulary, not even the user's own terms. If the idea leans on a coined phrase, translate the phrase too.
3. Do not upgrade weak links. Do not smooth logic. If a step is missing, the echo must show the hole instead of bridging it.
4. No selling, no encouragement, no hedging. Flat is the whole point.
5. End with one line: what the idea is when the clothes come off, stated plainly, including whether it survives the strip.

The echo is a mirror, not a judge. The user decides what the plain version tells them.
