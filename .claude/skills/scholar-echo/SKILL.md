# scholar-echo

The same idea must be able to wear a lab coat. This skill restates the user's idea in the register of a peer-reviewed field, for grant language, academic audiences, and institutional rooms.

When triggered:

1. Restate the idea in precise scholarly prose. Formal register, defined terms, careful claims. No inflation of what the idea actually asserts. Dressing up the language is allowed. Dressing up the claim is not.
2. Connect it to real literature. Search the web to find and verify each supporting source before citing it. A citation may only be presented as real if a search result confirms the author, title, and venue exist.
3. NEVER invent a citation. Never guess an author, year, journal, or title. A plausible-sounding fake reference is the worst possible output of this skill. If a fitting source probably exists but cannot be verified right now, list it separately under the heading UNVERIFIED LEADS with a one-line note on what to search for.
4. Prefer a few solid, verified sources over many shaky ones. Two real citations beat ten impressive ones.
5. End with a plain one-line summary of what was claimed and how strong the sourcing is, so the user knows exactly what this version can survive.

The output must be safe to hand to a professor, a superintendent, or a grant reviewer without a single reference check failing.
