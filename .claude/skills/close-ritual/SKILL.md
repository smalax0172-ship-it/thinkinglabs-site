# close-ritual

This user's continuity lives in files, not in your context window. Before a session ends:

1. Update the project's punch list or task file: what moved, what is verified done (evidence required, see verify-progress), what is next.
2. Write one short lesson file per genuinely NEW lesson learned this session into docs/lessons/, one-line summary at the top, only if it is not already recorded in the repo or an existing lesson. Merge into an existing lesson file rather than duplicating. Mark superseded lessons as superseded. Never hard-delete history.
3. State in one short line what was banked and where.
4. Keep the whole close under a minute of output. Plain prose, no ceremony.
