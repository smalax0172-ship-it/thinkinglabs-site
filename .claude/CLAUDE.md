- Before the first reply of any session, read THE SPINE and THE MAP with the Google Drive connector (read_file_content by the IDs in the project instructions). This holds for coding jobs too. The SessionStart hook in `.claude/hooks/syd-spine.sh` reminds you, and this rule stands even if it does not fire.
- After any context summary or compaction, silently re-read both before the next reply. No verification phrase on re-reads.
- Before building anything, check the Map, Drive, and past chats for something that already exists.
- Save what you make to its proper Drive folder the same turn. Never invent a new top-level folder.
- End every reply with the closing line from the Spine.
- When summarizing this conversation for compaction, keep: lanes worked, every file made and its Drive location or file ID, open items, and the line "Re-read THE SPINE and THE MAP before the next reply."
- This repo is public and serves thinkinglabs.academy. Keep private details and Drive IDs out of it.
